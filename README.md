# ระบบจองคิวและส่งเสริมพัฒนาการเด็ก (Early Intervention)

ระบบสำหรับคลินิกกระตุ้นพัฒนาการเด็ก ผู้ปกครองใช้ได้โดยไม่ต้องสมัครหรือล็อกอิน

- **ผู้ปกครอง:** จองคิว · เช็คคิวด้วยเบอร์มือถือ + รหัส 6 หลัก · ยืนยันนัด · เพิ่มนัดลงปฏิทิน · ดูรายงานพัฒนาการพร้อมกราฟ · ดูและพิมพ์ใบการบ้าน · อ่านใบความรู้แบบพลิกหน้า · ดาวน์โหลดใบงาน · แจ้งปัญหา · ประเมินความพึงพอใจ
- **เจ้าหน้าที่:** รายการนัด · แจ้งเตือนนัด (ข้อความ LINE / SMS) · เรื่องที่แจ้ง · รายงานพัฒนาการ · การบ้าน · แก้ไขหน้าจอง · วันหยุด · เวลาทำการ · ส่งออก Excel · อัปโหลดใบงานและใบความรู้

## ระบบประกอบด้วย 2 ส่วน

| ส่วน | อยู่ที่ไหน | เก็บอะไร |
|---|---|---|
| หน้าเว็บ (`docs/`) | GitHub Pages (ฟรี) | หน้าตาเว็บ ใบความรู้ และใบงานตั้งต้น **ไม่มีข้อมูลคนไข้** |
| ระบบหลังบ้าน (`apps-script/`) | Google Apps Script + Google Sheets ในบัญชี Google ของศูนย์ | ข้อมูลการจอง รายงานพัฒนาการ การบ้าน ไฟล์ที่อัปโหลด |

ข้อมูลคนไข้ทั้งหมดอยู่ใน Google Sheet ของศูนย์เท่านั้น ไม่ได้อยู่บน GitHub

## วิธีติดตั้ง (ทำครั้งเดียว ประมาณ 30 นาที)

### ขั้นที่ 1 สร้าง Google Sheet สำหรับเก็บข้อมูล
1. ล็อกอินบัญชี Google **ของศูนย์** (ไม่ใช้บัญชีส่วนตัว) แล้วเปิด https://sheets.new
2. ตั้งชื่อไฟล์ เช่น `ระบบจองคิว EI – ฐานข้อมูล`
3. **ห้ามแชร์ไฟล์นี้ให้คนนอก** เพราะมีข้อมูลเด็กและผู้ปกครอง

### ขั้นที่ 2 ใส่โค้ดหลังบ้าน
1. ใน Google Sheet กดเมนู **ส่วนขยาย (Extensions) › Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) แทน กด **บันทึก** (รูปแผ่นดิสก์)
3. กดรูปฟันเฟือง **การตั้งค่าโปรเจกต์ (Project Settings)** › เลื่อนลงไปที่ **พร็อพเพอร์ตีของสคริปต์ (Script properties)** › **เพิ่ม**
   - Property: `STAFF_PASSWORD`
   - Value: รหัสผ่านสำหรับเจ้าหน้าที่ (ยาวอย่างน้อย 10 ตัว ปนตัวเลขและตัวอักษร)
4. กลับไปหน้าโค้ด เลือกฟังก์ชัน `setup` ที่แถบด้านบน แล้วกด **เรียกใช้ (Run)**
   - Google จะขอสิทธิ์ ให้กด **ตรวจสอบสิทธิ์ › เลือกบัญชีของศูนย์ › ขั้นสูง › ไปที่โปรเจกต์ (ไม่ปลอดภัย) › อนุญาต**
     (ขึ้นคำว่า "ไม่ปลอดภัย" เพราะเป็นโค้ดที่ศูนย์เขียนเอง ไม่ได้ผ่านการตรวจของ Google)
   - เมื่อเสร็จ จะมีแผ่นงาน `docs` และ `assets` เพิ่มใน Google Sheet และมีโฟลเดอร์ใน Google Drive ไว้เก็บไฟล์ที่อัปโหลด

### ขั้นที่ 3 เปิดให้หน้าเว็บเชื่อมต่อได้ (Deploy)
1. กดปุ่ม **การทำให้ใช้งานได้ (Deploy) › การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดรูปฟันเฟืองข้าง "เลือกประเภท" › **เว็บแอป (Web app)**
3. ตั้งค่า
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
4. กด **ทำให้ใช้งานได้ (Deploy)** แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
5. เปิดไฟล์ [`docs/js/config.js`](docs/js/config.js) ใน GitHub › กดรูปดินสอ › วาง URL ลงใน `API_URL: ""` เช่น
   ```js
   API_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
   ```
   แล้วกด **Commit changes**

### ขั้นที่ 4 เปิดหน้าเว็บด้วย GitHub Pages
1. ใน GitHub ไปที่ **Settings › Pages**
2. Source: **Deploy from a branch** · Branch: **main** · Folder: **/docs** › **Save**
3. รอ 1–2 นาที จะได้ลิงก์ เช่น `https://meentratam11-cpu.github.io/early-intervention/`

> GitHub Pages แบบฟรีใช้ได้กับรีพอซิทอรีสาธารณะ (Public) เท่านั้น รีพอนี้มีแค่โค้ดและเอกสารความรู้ ไม่มีข้อมูลคนไข้ จึงเปิดเป็นสาธารณะได้ หรือใช้ GitHub Pro เพื่อเปิด Pages จากรีพอส่วนตัว

### ขั้นที่ 5 เริ่มใช้งาน
1. เปิดลิงก์หน้าเว็บ › กดปุ่ม **เจ้าหน้าที่** (มุมขวาบน) › ใส่รหัสผ่านจากขั้นที่ 2
2. จะมีแถบสีเหลือง **"ระบบยังว่าง"** › กด **นำเข้าข้อมูลตั้งต้น**
   ได้การตั้งค่า บริการ ช่วงเวลา วันหยุด คลังกิจกรรม ใบงาน 3 ชิ้น และใบความรู้ 7 เล่ม
3. ตั้งรหัส PIN เจ้าหน้าที่ (ใช้ล็อกหน้าจอเมื่อไม่ได้ใช้งาน)
4. ไปที่ **ติดต่อเรา › แก้ไขข้อมูลติดต่อ** ใส่เบอร์โทรและที่อยู่ของศูนย์
5. ลองจองคิวทดสอบ 1 รายการ แล้วยกเลิก ก่อนแจกลิงก์ให้ผู้ปกครอง
6. ใส่ลิงก์หน้าเว็บเป็นปุ่ม "จองคิว" ในเว็บไซต์ Canva ของศูนย์

## การดูแลระบบ

- **ข้อมูลอยู่ที่ไหน:** Google Sheet แผ่นงาน `docs` (1 แถวต่อ 1 เอกสาร เก็บเป็น JSON) ไฟล์อัปโหลดอยู่ในโฟลเดอร์ Google Drive ชื่อ "Early Intervention – ไฟล์อัปโหลด"
- **สำรองข้อมูล:** ใน Google Sheet กด **ไฟล์ › ทำสำเนา** เป็นประจำ เช่น ทุกเดือน
- **เปลี่ยนรหัสผ่านเจ้าหน้าที่:** แก้ค่า `STAFF_PASSWORD` ใน Script properties (เจ้าหน้าที่ที่ล็อกอินไว้จะหลุดภายใน 12 ชั่วโมง)
- **แก้โค้ดหลังบ้าน:** แก้ใน Apps Script แล้วกด **Deploy › จัดการการทำให้ใช้งานได้ › แก้ไข (ดินสอ) › เวอร์ชัน: เวอร์ชันใหม่ › Deploy** (URL เดิมยังใช้ได้)
- **โควตาของ Google (บัญชีฟรี):** สคริปต์ทำงานได้ราว 90 นาทีต่อวัน เพียงพอสำหรับคลินิกทั่วไป หน้าเว็บจะดึงข้อมูลใหม่ทุก 20 วินาทีเฉพาะตอนเปิดหน้าไว้

## สำหรับนักพัฒนา

- `src/app.html` — หน้าเว็บต้นฉบับ (เวอร์ชัน claude.ai)
- `tools/build_web.py` — สร้าง `docs/index.html` จาก `src/app.html` (`python3 tools/build_web.py`)
- `docs/js/shim.js` — ตัวเชื่อมหน้าเว็บกับ Apps Script (จำลองคำสั่ง `claude.use("db" | "user" | "assets" | "downloads")`)
- `docs/seed.json` — ข้อมูลตั้งต้น (ไม่มีข้อมูลคนไข้) · `docs/files/` — ใบความรู้และใบงาน
- `tools/mock-server.js` — ทดสอบในเครื่อง: `node tools/mock-server.js` แล้วเปิด http://localhost:8788 (รหัสเจ้าหน้าที่ `test1234`)
